Caddie Alpha for Windows
========================

系统要求

- Windows 10 或 Windows 11，64 位
- 推荐安装 Microsoft Edge WebView2 Runtime（多数 Windows 10/11 已自带）

使用方法

1. 解压完整的 Caddie-Windows 文件夹，不要只把 Caddie.exe 单独拖出来。
2. 双击 Caddie.exe。
3. 若 Windows SmartScreen 显示“Windows 已保护你的电脑”，点击“更多信息”，
   核对应用名称为 Caddie 后点击“仍要运行”。
4. 按首次引导选择应用内 API、连接 Claude/Codex，或暂时不用 AI。

外部 Agent 接入

- 首次打开后，Caddie 会在 %USERPROFILE%\.caddie\bin\ 生成稳定入口：
  caddie-mcp.cmd 与 caddie-agent.cmd。
- 在 Caddie 的 Agent 接入页执行一键接入后，请完整退出并重启 Claude 或 Codex。
- 移动程序文件夹后，请重新打开一次 Caddie.exe，让稳定入口自动刷新。

数据与隐私

- 数据默认保存在：%USERPROFILE%\.caddie\
- 删除程序文件夹不会删除本地职业资料。
- API Key 仅保存在本机。
- 匿名使用分析默认关闭，当前 Alpha 即使开启也不会上传云端。

注意

当前邀请测试版尚未购买 Windows 代码签名证书，因此首次运行可能出现 SmartScreen
提醒。不要关闭 Windows Defender 或系统全局安全设置。

当前 Windows Alpha 暂不支持应用内自动替换升级。收到新版压缩包后，请退出 Caddie，
解压到新文件夹再运行；%USERPROFILE%\.caddie\ 中的数据会继续保留。
