# Caddie brand assets

- `caddie-logo-master.svg` — transparent master logo.
- `caddie-app-icon.svg` — full macOS/iOS app icon artwork.
- `caddie-mac-template.svg` — monochrome template icon for menu bar and toolbar use.
- `components/` — separately reusable vector layers.
- `caddie-brand-wallpaper-4k.svg` — 3840 × 2160 brand display artwork.

The master mark uses `#3370FF` as its core color. Keep the main C and its accent
facets aligned to the same 1024 × 1024 view box when recombining components.
