# qiuzhao-feed integration

Source: https://github.com/xixicc186/xixicc2027

This directory keeps a local copy of the public `qiuzhao-feed` skill and a
sample `jobs.json` snapshot for field-mapping tests. Caddie does not serve this
snapshot as production data; the app syncs the latest public feed from:

https://raw.githubusercontent.com/xixicc186/xixicc2027/main/jobs.json
